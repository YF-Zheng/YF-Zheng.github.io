# Yanfeng Zheng · Personal Portfolio

Personal website: https://yf-zheng.github.io/

A responsive, buildless portfolio hosted with GitHub Pages. The site uses plain HTML, CSS and JavaScript with no runtime dependencies or analytics.

## Edit

- `index.html`: introduction, projects, profile and contact links.
- `style.css`: layout, typography, colors and responsive styles.
- `script.js`: copyright year and email copy feedback.

GitHub Pages serves the root of `main`. Push changes to publish updates. GPU Tetris remains independently deployed at `/GPU-tetris/`.
